# Static Site Generator Lite

A lightweight, zero-dependency static site generator written in Python. Convert your Markdown notes into a clean, readable website.

## Features
- Converts `.md` files to `.html`.
- Supports basic front-matter for titles and dates.
- Automatic index page generation.
- Simple CSS theme included.

## Usage
1. Place your markdown files in the `content/` directory.
2. Run `python main.py`.
3. Find your generated site in the `public/` directory.
